## صفحة 3

تقديم

فى إطار التطوير المستمر لمنظومة التعليم، واستكمالاً لمنظومة التطوير التى بدأت خططها من مرحلة رياض الأطفال والمستمرة إلى نهاية المرحلة الثانوية وفقًا لرؤية مصر (٢٠٣٠)، وخطة الوزارة لتطوير التعليم - فقد تم إعداد هذا الكتاب لاستكمال وتنفيذ عمليات تطوير مناهج المرحلة الإعدادية لإحداث نقلة نوعية فى طريقة إعداد طلاب مصر لمواجهة تحديات المستقبل.

يُسعدنا أن نقدم هذا الكتاب لمقرر الرياضيات للصف الثالث الإعدادى للفصل الدراسى الأول، والذى يتضمن مجموعة من المهام والأداءات التى تساعد الطلاب على حل المشكلات الرياضية، وذلك لتحقيق نواتج التعلم لمواجهة تحديات القرن الحادى والعشرين، والذى واكبت بدايته ثورة متسارعة فى المعلومات وتكنولوجيا الاتصالات.

يهدف المنهج إلى إحداث نقلة نوعية فى تعليم الرياضيات وتعلمها، كما يهدف أيضًا إلى توفير وسيلة فعالة لتحقيق أهداف نهج التعليم على نحو تكاملى عن طريق الآتي:
• التأكيد على الدور الإيجابي للطالب فى عملية التعلم.
• تضمين المنهج المعارف والمهارات والقيم والاتجاهات الإيجابية اللازمة للتعلم وللمواطنة الصالحة والعمل المنتج والمشاركة الفاعلة فى تحقيق برامج التنمية المستدامة.
• تضمين المنهج التوجهات الإيجابية فى بناء المناهج، مثل مهارات التفكير ومهارات حل المشكلات ومهارات التعلم الذاتى والتعلم التعاونى والتواصل الجيد مع مصادر المعرفة.
• تنمية المهارات الأدائية من خلال التركيز على التعلم الذاتى والعمل التعاونى.
• تحقيق التكامل بين الرياضيات والمواد الدراسية عبر المراحل المختلفة.
• إتاحة الفرصة للطلاب لاختيار الأنشطة المناسبة لقدراتهم وميولهم وحاجاتهم.

فكر وناقش !

معلومة سابقة
قوانين الأسس :
لأي عددين حقيقيين a، b حيث a≠0، b≠0، وعددين صحيحين m، n يكون :
1) a^m × a^n = a^(m+n)
2) a^m ÷ a^n = a^(m-n)
3) (a × b)^m = a^m × b^m
4) (a/b)^m = a^m / b^m
5) a^-n = 1/a^n
6) a^0 = 1

بصفة عامة:
لأي عدد حقيقي a لا يساوي الصفر، وعددين صحيحين m، n يكون :
(a^m)^n = a^(m×n)
فمثلاً :
• (5^4)^2 = 5^(4×2) = 5^8
• (7^-2)^5 = 7^(-2×5) = 7^-10

الدالة التربيعية
الدالة التربيعية هي دالة من الدرجة الثانية في متغير واحد، تمثل بمنحنى يُسمى «قطعًا مكافئًا»، وهو منحنى متماثل حول مستقيم رأسي يُسمى محور التماثل ويمر برأس المنحنى.

الصيغة القياسية للدالة التربيعية
الصيغة القياسية للدالة التربيعية f هي: f(x) = ax² + bx + c حيث a ≠ 0
• الإحداثي x لرأس المنحنى: x = -b / 2a
• الإحداثي y لرأس المنحنى: y = f(-b / 2a)
• رأس المنحنى: (-b / 2a, f(-b / 2a))
• المقطع y يساوي c

المجال المشترك لدوال الكسور الجبرية النسبية
المجال المشترك لدالتين هو تقاطع مجاليهما، أي مجموعة القيم التي تكون فيها الدالتان معرفتين معاً.

مجال f هو R - Z1 حيث Z1 مجموعة أصفار مقام f(x)
ومجال g هو R - Z2 حيث Z2 مجموعة أصفار مقام g(x)

مجال f = {1, 2} - R
مجال g = {2, 3} - R
فأي العبارتين الآتيتين صحيحة:
1 المجال المشترك = {2} - R
2 المجال المشترك = {1, 2, 3} - R

تساوى دوال الكسور الجبرية النسبية
تساوى دالتان من دوال الكسور الجبرية النسبية إذا تحقق الشرطان تالياً معاً :
1 تطابق المجال (أي الدالتان لهما نفس المجال تماماً).
2 تكافؤ القاعدة (أي عند تبسيط القاعدتين إلى أبسط صورة، تكونان متطابقتين).
أي أن :
لأي دالتين f , g من دوال الكسور الجبرية النسبية تكون f = g إذا تحقق الشرطان :
1 Df = Dg 2 f(x) = g(x) لكل x ∈ (Df ∩ Dg)

تقييم ذاتى 3
إذا كانت :
f(x) = x + 2 / x² + 2x
g(x) = x² + 2x / x³ + 2x²
فأثبت أن f = g

مثال 3
إذا كانت : f(x) = x² - 3x / x² - 6x + 9 , g(x) = 4x / 4x - 12 فأثبت أن f = g :
∴ f(x) = x² - 3x / x² - 6x + 9 = x(x - 3) / (x - 3)(x - 3)
∴ Df = R - {3} , f(x) = x / x - 3
∴ g(x) = 4x / 4x - 12 = 4x / 4(x - 3)
∴ Dg = R - {3} , g(x) = x / x - 3
∴ مجال f = مجال g , f(x) = g(x) لكل x ∈ R - {3}
∴ f = g

تقييم ذاتى 4
إذا كانت :
f(x) = 4 / 4x - 20
g(x) = x + 5 / x² - 25
فأثبت أن :
f(x) = g(x)
لكل x تنتمى إلى المجال المشترك، وأوجد هذا المجال.

مثال 4
إذا كانت : f(x) = x / x² - 2x , g(x) = x² + 2x + 4 / x³ - 8
فأثبت أن : f(x) = g(x) لكل x تنتمى إلى المجال المشترك للدالتين f, g وأوجد هذا المجال.
∴ f(x) = x / x² - 2x = x / x(x - 2)
∴ Df = R - {0, 2} , f(x) = 1 / x - 2
∴ g(x) = x² + 2x + 4 / x³ - 8 = x² + 2x + 4 / (x - 2)(x² + 2x + 4)
∴ Dg = R - {2} , g(x) = 1 / x - 2
∴ المجال المشترك للدالتين f , g هو R - {0, 2}
لاحظ أن :
∴ f(x) = g(x) لكل x تنتمى إلى المجال المشترك R - {0, 2} مجال f ≠ مجال g
