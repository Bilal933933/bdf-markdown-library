مقلوب دالة الكسر الجبري النسبي
إذا كانت f(x) دالة كسر جبري نسبي فإن مقلوب دالة الكسر الجبري النسبي g(x) هو
g(x) = [f(x)]⁻¹ = 1 / f(x)
ومجال دالة المقلوب هو جميع الأعداد الحقيقية مع استبعاد قيم x التي تجعل بسط ومقام الدالة f(x) يساويان الصفر.
فمثلاً:
إذا كانت f(x) = (x - 2) / (x + 3) دالة مجالها R - {-3} فإن مقلوب الدالة هو g(x) حيث
g(x) = [f(x)]⁻¹ = 1 / f(x) = (x + 3) / (x - 2)
ومجال الدالة g هو R - {-3, 2}

مثال 1
أوجد قيمة x في كل من الأشكال الآتية:

(1)
مثلث قائم الزاوية، الزاوية 45°، الوتر 16، الضلع المجاور x.
cos 45° = x / 16
1 / √2 = x / 16
x = 16 / √2 = 8√2

(2)
مثلث قائم الزاوية، الزاوية 30°، الضلع المقابل 4، الضلع المجاور x.
tan 30° = 4 / x
1 / √3 = 4 / x
x = 4√3

(3)
مثلث قائم الزاوية، الزاوية 60°، الضلع المقابل 20√3، الوتر x.
sin 60° = 20√3 / x
√3 / 2 = 20√3 / x
x = 40
