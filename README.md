# bdf-markdown-library

مكتبة لتحويل كتب PDF العربية إلى Markdown نظيف عبر واجهة ويب (Next.js) وخلفية (FastAPI)، مع سجل أحداث مرئي لكل تحويل.

## المكوّنات

| المجلد | الدور |
|--------|-------|
| `frontend/` | الواجهة (Next.js): الرفع، الحالة، سجل الأحداث، عرض Markdown |
| `backend/` | الخلفية (FastAPI): الاستخراج، الجودة، OCR، الـAPI |
| `المدرسة/` | بيانات: ملفات PDF المدخلة والمخرجات (محتوى، ليست كود) |

## سير التحويل

1. ارفع PDF من الواجهة أو `POST /api/v1/conversions`.
2. طبقة نصية → استخراج مباشر (`extract/pdf_layer.py`)؛ ممسوح → OCR تلقائي (PaddleOCR/Gemini).
3. تابع التقدم والأحداث من بطاقة التحويل في الواجهة.

## المتطلبات

- Python 3.12 و[uv](https://docs.astral.sh/uv/) للباك
- Node.js للواجهة

## التحقق من الباك

من مجلد `backend/` شغّل:

```powershell
.\validate.ps1
```

يقوم الأمر بتثبيت الاعتماديات من `backend/uv.lock` ثم يشغّل الاختبارات، وفحص Ruff، وفحص الأنواع عبر mypy.

## الكتب المعالجة

- كتب اللغة العربية للمرحلة الابتدائية (الصف الأول والصف السادس — الفصل الدراسي الثاني).
