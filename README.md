# bdf-markdown-library

مكتبة لتحويل كتب PDF العربية إلى ملفات Markdown نصية نظيفة، مع أدوات مراجعة وتصحيح تلقائية.

## نظرة عامة

هذا المشروع يحوّل ملفات PDF (خاصة الكتب العربية، الممسوحة ضوئيًا أو ذات الطبقة النصية) إلى ملفات Markdown منظمة، موزّعة على أجزاء، مع مرحلة مراجعة وجودة شاملة.

## المخرجات

- مجلد لكل كتاب يحوي ملفات `part-XX.md` (كل ملف ~40 صفحة).
- صيغة الصفحة: `## صفحة <رقم>` تليها النص.
- ترويسة كل جزء: `# <اسم الكتاب> — الجزء N (صفحات a-b)`.

## الأدوات (`_ocr/`)

| السكربت | الاستخدام |
|---------|-----------|
| `ocr-book-jpx.mjs` | OCR كامل لكتاب ممسوح (JPEG2000 وصيغ عادية) |
| `render-test.mjs` | اختبار صفحة وسطية قبل تشغيل OCR كامل |
| `extract-text.mjs` | استخراج مباشر للطبقة النصية |
| `fix-pages.mjs` | تنظيف + OCR للصفحات القصيرة/المحطمة |
| `verify-book.mjs` | تقرير هيكلي (الصفحات/الفارغة/الفاشلة) |

## المتطلبات

- Node.js
- Tesseract.js (مع خط `ara_best` للعربية)
- pdfjs-dist

## الكتب المعالجة

- كتب اللغة العربية للمرحلة الابتدائية (الصف الأول والصف السادس — الفصل الدراسي الثاني).

## الترخيص

راجع ملفات المشروع للتفاصيل.
