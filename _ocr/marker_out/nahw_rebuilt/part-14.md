# كيف تتقن النحو — الجزء 14 (صفحات 521-553)

## صفحة 521

٥٢٠ | كَيْفَ تُفْهَمُ النَّحْوُ

| الأَمِينَا | الأَمِينَا: مَفْعُولٌ بِهِ مَنْصُوبٌ ، وَعَلَامَتُهُ نَصْبِهِ الْفَتْحَةُ. |
| | وَجُمْلَةُ (خَنْتَ الأَمِينَا) مَعْطُوفَةٌ عَلَى جُمْلَةِ (هَلْ أَحْدَثْتَ صَرَمَا) فَهِيَ فِي مَحَلِّ نَصْبٍ مِثْلُهَا. |
| | إِذَا لَمْ نُحْمِهِنَّ، فَلَا بَقِينَا  لِشَيْءٍ بَعْدَهُنَّ، وَلَا حَيِينَا |
| إِذَا | ظَرْفٌ لِمَا يُسْتَقْبَلُ مِنَ الزَّمَانِ، خَافِضٌ لِشَرْطِهِ، مَنْصُوبٌ بِجَوَابِهِ، مَبْنِيٌّ عَلَى السُّكُونِ فِي مَحَلِّ نَصْبٍ. |
| لَمْ نُحْمِهِنَّ | لَمْ: حَرْفُ نَفْيٍ وَقَلْبٍ وَجَزْمٍ. |
| | نُحْمِهِنَّ: فِعْلٌ مُضَارِعٌ مَجْزُومٌ بِلَمْ، وَعَلَامَةُ جَزْمِهِ حَذْفُ حَرْفِ الْعِلَّةِ. وَالْفَاعِلُ: ضَمِيرٌ مُسْتَتِرٌ تَقْدِيرُهُ (نَحْنُ)، |
| | وَالْهَاءُ: ضَمِيرٌ مُتَّصِلٌ مَبْنِيٌّ عَلَى الضَّمِّ فِي مَحَلِّ نَصْبٍ مَفْعُولٌ بِهِ، وَالنُّونُ حَرْفٌ دَالٌّ عَلَى الْإِنَاثِ، وَالْجُمْلَةُ الْفِعْلِيَّةُ فِي مَحَلِّ جَرٍّ بِإِضَافَةِ إِذَا إِلَيْهَا. |
| فَلَا بَقِينَا | الْفَاءُ: وَاقِعَةٌ فِي جَوَابِ إِذَا. لَا: نَافِيَةٌ. بَقِينَا: فِعْلٌ مَاضٍ مَبْنِيٌّ عَلَى السُّكُونِ، وَنَا: ضَمِيرٌ مُتَّصِلٌ مَبْنِيٌّ عَلَى السُّكُونِ فِي مَحَلِّ رَفْعِ فَاعِلٍ، وَالْجُمْلَةُ الْفِعْلِيَّةُ جَوَابُ إِذَا لَا مَحَلَّ لَهَا مِنَ الْإِعْرَابِ. |
| لِشَيْءٍ بَعْدَهُنَّ، | لِ: حَرْفُ جَرٍّ مَبْنِيٌّ عَلَى الْكَسْرِ. |
| | شَيْءٍ: اسْمٌ مَجْرُورٌ بِاللَّامِ، وَعَلَامَةُ جَرِّهِ الْكَسْرَةُ، وَالْجَارُّ وَالْمَجْرُورُ مُتَعَلِّقَانِ بِالْفِعْلِ بَقِينَا. |
| | بَعْدَهُنَّ: ظَرْفُ زَمَانٍ مُتَعَلِّقٌ بِالْفِعْلِ بَقِينَا. |
| | وَالْهَاءُ: ضَمِيرٌ مُتَّصِلٌ مَبْنِيٌّ عَلَى الضَّمِّ فِي مَحَلِّ جَرٍّ بِالْإِضَافَةِ، وَالنُّونُ حَرْفٌ دَالٌّ عَلَى جَمَاعَةِ الْإِنَاثِ. |
| وَلَا حَيِينَا | الْوَاوُ: حَرْفُ عَطْفٍ مَبْنِيٌّ عَلَى الْفَتْحِ. لَا: زَائِدَةٌ لِتَأْكِيدِ النَّفْيِ. |
| | حَيِينَا: فِعْلٌ مَاضٍ مَبْنِيٌّ عَلَى السُّكُونِ، نَا: ضَمِيرٌ مُتَّصِلٌ مَبْنِيٌّ عَلَى السُّكُونِ فِي مَحَلِّ رَفْعِ فَاعِلٍ، وَالْجُمْلَةُ الْفِعْلِيَّةُ مَعْطُوفَةٌ عَلَى جُمْلَةِ (لَا بَقِينَا) لَا مَحَلَّ لَهَا مِثْلُهَا. |

## صفحة 522

٥٢١ | كَيْفَ تَتْقِنُ النَّحْوَ ؟

إِعْرَابُ بَعْضِ أَبْيَاتِ نَهْجِ الْبُرْدَةِ لِلْبُوصِيرِيّ

٣٤- مُحَمَّدٌ سَيِّدُ الْكَوْنَيْنِ وَالثَّقَلَيْنِ وَالْفَرِيقَيْنِ مِنْ عَرَبٍ وَمِنْ عَجَمِ

| مُحَمَّدٌ | مُبْتَدَأٌ مَرْفُوعٌ، وَعَلَامَةُ رَفْعِهِ الضَّمَّةُ الظَّاهِرَةُ. |
| :--- | :--- |
| سَيِّدُ | خَبَرٌ مَرْفُوعٌ، وَعَلَامَةُ رَفْعِهِ الضَّمَّةُ الظَّاهِرَةُ، وَهُوَ مُضَافٌ. |
| الْكَوْنَيْنِ | مُضَافٌ إِلَيْهِ، مَجْرُورٌ، وَعَلَامَةُ جَرِّهِ الْيَاءُ؛ لِأَنَّهُ مُثَنَّى. |
| وَ | حَرْفُ عَطْفٍ مَبْنِيٌّ عَلَى الْفَتْحِ لَا مَحَلَّ لَهُ مِنَ الْإِعْرَابِ. |
| الثَّقَلَيْنِ | اِسْمٌ مَعْطُوفٌ عَلَى (الْكَوْنَيْنِ) مَجْرُورٌ، وَعَلَامَةُ جَرِّهِ الْيَاءُ؛ لِأَنَّهُ مُثَنَّى. |
| وَ | حَرْفُ عَطْفٍ مَبْنِيٌّ عَلَى الْفَتْحِ لَا مَحَلَّ لَهُ مِنَ الْإِعْرَابِ. |
| الْفَرِيقَيْنِ | اِسْمٌ مَعْطُوفٌ عَلَى (الْكَوْنَيْنِ) مَجْرُورٌ، وَعَلَامَةُ جَرِّهِ الْيَاءُ؛ لِأَنَّهُ مُثَنَّى. |
| مِنْ | حَرْفُ جَرٍّ مَبْنِيٌّ عَلَى السُّكُونِ لَا مَحَلَّ لَهُ مِنَ الْإِعْرَابِ. |
| عَرَبٍ | اِسْمٌ مَجْرُورٌ، وَعَلَامَةُ جَرِّهِ الْكَسْرَةُ الظَّاهِرَةُ. |
| وَ | حَرْفُ عَطْفٍ مَبْنِيٌّ عَلَى الْفَتْحِ لَا مَحَلَّ لَهُ مِنَ الْإِعْرَابِ. |
| مِنْ | حَرْفُ جَرٍّ مَبْنِيٌّ عَلَى السُّكُونِ لَا مَحَلَّ لَهُ مِنَ الْإِعْرَابِ. |
| عَجَمِ | اِسْمٌ مَجْرُورٌ، وَعَلَامَةُ جَرِّهِ الْكَسْرَةُ الظَّاهِرَةُ. |

وَالْجَارُّ وَالْمَجْرُورُ مَعْطُوفَانِ عَلَى ( مِنْ عَرَبٍ ).
وَالْجُمْلَةُ الاسْمِيَّةُ: (مُحَمَّدٌ سَيِّدٌ) اسْتِئْنَافِيَّةٌ، لَا مَحَلَّ لَهَا مِنَ الْإِعْرَابِ.

## صفحة 523

| ٥٢٢ | كَيْفَ تُتْقِنُ النَّحْوَ |
| :--- | :--- |
| **٣٥- نَبِيُّنَا الْآمُرُ النَّاهِي فَلَا أَحَدَ أَبَرَّ فِي قَوْلِ لَا مِنْهُ وَلَا نَعَمَ** |
| **نَبِيُّنَا** | خَبَرٌ لِمُبْتَدَإٍ مَحْذُوفٍ أَوْ خَبَرٌ ثَانٍ لِـ (مُحَمَّد)، مَرْفُوعٌ وَعَلَامَةُ رَفْعِهِ الضَّمَّةُ الظَّاهِرَةُ، وَهُوَ مُضَافٌ.<br>نَا: ضَمِيرٌ مُتَّصِلٌ مَبْنِيٌّ عَلَى السُّكُونِ، فِي مَحَلِّ جَرٍّ بِالْإِضَافَةِ. |
| **الْآمُرُ** | خَبَرٌ ثَانٍ، أَوْ صِفَةٌ، مَرْفُوعٌ، وَعَلَامَةُ رَفْعِهِ الضَّمَّةُ الظَّاهِرَةُ. |
| **النَّاهِي** | خَبَرٌ ثَالِثٌ، أَوْ صِفَةٌ ثَانِيَةٌ، مَرْفُوعٌ، وَعَلَامَةُ رَفْعِهِ الضَّمَّةُ الْمُقَدَّرَةُ عَلَى الْيَاءِ؛ لِلثِّقْلِ. |
| **فَلَا** | الْفَاءُ: اسْتِئْنَافِيَّةٌ، لَا: نَافِيَةٌ تَعْمَلُ عَمَلَ لَيْسَ. |
| **أَحَدَ** | اسْمُهَا، مَرْفُوعٌ، وَعَلَامَةُ رَفْعِهِ الضَّمَّةُ الظَّاهِرَةُ. |
| **أَبَرَّ** | خَبَرُهَا، مَنْصُوبٌ، وَعَلَامَةُ نَصْبِهِ الْفَتْحَةُ الظَّاهِرَةُ.<br>وَالْجُمْلَةُ الاِسْمِيَّةُ: (لَا أَحَدَ أَبَرَّ) اسْتِئْنَافِيَّةٌ، لَا مَحَلَّ لَهَا مِنَ الْإِعْرَابِ، وَهِيَ جُمْلَةٌ اسْمِيَّةٌ. |
| **فِي** | حَرْفُ جَرٍّ مَبْنِيٌّ عَلَى السُّكُونِ لَا مَحَلَّ لَهُ مِنَ الْإِعْرَابِ. |
| **قَوْلِ** | اسْمٌ مَجْرُورٌ بِـ (فِي)، وَعَلَامَةُ جَرِّهِ الْكَسْرَةُ الظَّاهِرَةُ.<br>وَالْجَارُّ وَالْمَجْرُورُ مُتَعَلِّقَانِ بِاسْمِ التَّفْضِيلِ (أَبَرَّ). |
| **لَا** | فِي مَوْضِعِ الْمُضَافِ إِلَيْهِ عَلَى الْحِكَايَةِ. |
| **مِنْهُ** | حَرْفُ جَرٍّ مَبْنِيٌّ عَلَى السُّكُونِ.<br>وَالْهَاءُ: ضَمِيرٌ مُتَّصِلٌ مَبْنِيٌّ عَلَى الضَّمِّ، فِي مَحَلِّ جَرٍّ بِـ ( مِنْ ).<br>وَالْجَارُّ وَالْمَجْرُورُ مُتَعَلِّقَانِ بِاسْمِ التَّفْضِيلِ (أَبَرَّ). |
| **وَلَا** | وَ: حَرْفُ عَطْفٍ مَبْنِيٌّ عَلَى الْفَتْحِ، لَا: حَرْفُ نَفْيٍ. |
| **نَعَمَ** | مَعْطُوفَةٌ عَلَى ( لَا ) الْمُضَافِ إِلَيْهِ، فِي مَوْضِعِ جَرٍّ عَلَى الْحِكَايَةِ؛ لِأَنَّ الْمُرَادَ لَفْظُهَا. |

## صفحة 524

٥٢٣ | ﴿ كَيْفَ تُفَنُّ النَّحْوُ ﴾

٣٦- هُوَ الْحَبِيبُ الَّذِي تُرْجَى شَفَاعَتُهُ لِكُلِّ هَوْلٍ مِنَ الْأَهْوَالِ مُقْتَحَمِ

| هُوَ | ضَمِيرُ رَفْعٍ مُنْفَصِلٍ، مَبْنِيٌّ عَلَى الْفَتْحِ، فِي مَحَلِّ رَفْعٍ مُبْتَدَأٍ. |
| :--- | :--- |
| الْحَبِيبُ | خَبَرٌ مَرْفُوعٌ، وَعَلَامَةُ رَفْعِهِ الضَّمَّةُ الظَّاهِرَةُ. |
| | وَجُمْلَةُ: (هُوَ الْحَبِيبُ) اسْتِئْنَافِيَّةٌ، لَا مَحَلَّ لَهَا مِنَ الْإِعْرَابِ. |
| الَّذِي | اسْمٌ مَوْصُولٌ، مَبْنِيٌّ عَلَى السُّكُونِ، فِي مَحَلِّ رَفْعِ صِفَةٍ لِـ (الْحَبِيبُ). |
| تُرْجَى | فِعْلٌ مُضَارِعٌ مَبْنِيٌّ لِلْمَجْهُولِ مَرْفُوعٌ، وَعَلَامَةُ رَفْعِهِ الضَّمَّةُ الْمُقَدَّرَةُ؛ لِلتَّعَذُّرِ. |
| شَفَاعَتُهُ | نَائِبُ فَاعِلٍ مَرْفُوعٌ، وَعَلَامَةُ رَفْعِهِ الضَّمَّةُ الظَّاهِرَةُ. |
| | وَالْهَاءُ: ضَمِيرٌ مُتَّصِلٌ مَبْنِيٌّ عَلَى الضَّمِّ فِي مَحَلِّ جَرٍّ بِالْإِضَافَةِ. |
| | الْجُمْلَةُ الْفِعْلِيَّةُ: (تُرْجَى شَفَاعَتُهُ) : صِلَةُ الْمَوْصُولِ، لَا مَحَلَّ لَهَا مِنَ الْإِعْرَابِ. |
| لِكُلِّ | اللَّامُ: حَرْفُ جَرٍّ مَبْنِيٌّ عَلَى الْكَسْرِ لَا مَحَلَّ لَهُ مِنَ الْإِعْرَابِ. |
| | كُلِّ: اسْمٌ مَجْرُورٌ بِاللَّامِ، وَعَلَامَةُ جَرِّهِ الْكَسْرَةُ الظَّاهِرَةُ، وَهُوَ مُضَافٌ. |
| | وَالْجَارُّ وَالْمَجْرُورُ مُتَعَلِّقَانِ بِالْفِعْلِ (تُرْجَى). |
| هَوْلٍ | مُضَافٌ إِلَيْهِ، مَجْرُورٌ، وَعَلَامَةُ جَرِّهِ وَعَلَامَةُ جَرِّهِ الْكَسْرَةُ الظَّاهِرَةُ. |
| مِنَ | حَرْفُ جَرٍّ مَبْنِيٌّ عَلَى السُّكُونِ الْمُقَدَّرِ تَخَلُّصًا مِنَ الْتِقَاءِ السَّاكِنَيْنِ لَا مَحَلَّ لَهُ مِنَ الْإِعْرَابِ. |
| الْأَهْوَالِ | اسْمٌ مَجْرُورٌ بِـ (مِنْ)، وَعَلَامَةُ جَرِّهِ الْكَسْرَةُ الظَّاهِرَةُ. |
| | وَالْجَارُّ وَالْمَجْرُورُ مُتَعَلِّقَانِ بِصِفَةٍ مَحْذُوفَةٍ لِـ (هَوْلٍ). |
| مُقْتَحَمِ | صِفَةٌ ثَانِيَةٌ لِـ (هَوْلٍ)، مَجْرُورَةٌ، وَعَلَامَةُ جَرِّهَا الْكَسْرَةُ الظَّاهِرَةُ. |

## صفحة 525

| ٥٢٤ | ﷽ كَيْفَ تُعْرِبُ النَّحْوُ ؟ |
| :--- | :--- |
| **٣٧- دَعَا إِلَى اللَّهِ فَالْمُسْتَمْسِكُونَ بِهِ مُسْتَمْسِكُونَ بِحَبْلٍ غَيْرِ مُنْفَصِمٍ** | |
| دَعَا | فِعْلٌ مَاضٍ، مَبْنِيٌّ عَلَى الْفَتْحِ الْمُقَدَّرِ عَلَى الْأَلِفِ، لِلتَّعَذُّرِ، وَالْفَاعِلُ ضَمِيرٌ مُسْتَتِرٌ جَوَازًا تَقْدِيرُهُ (هُوَ). <br> وَالْجُمْلَةُ الْفِعْلِيَّةُ: (دَعَا) اسْتِئْنَافِيَّةٌ، لَا مَحَلَّ لَهَا مِنَ الْإِعْرَابِ. |
| إِلَى | حَرْفُ جَرٍّ مَبْنِيٌّ عَلَى السُّكُونِ لَا مَحَلَّ لَهُ مِنَ الْإِعْرَابِ. |

# الْخَاتِمَةُ

أَحْمَدُ اللهَ عَلَى تَوْفِيقِهِ لِي فِي تَأْلِيفِ هَذَا الْكِتَابِ، وَأَسْأَلُ اللهَ - تَعَالَى - أَنْ يَتَقَبَّلَهُ مِنِّي، وَأَنْ يَنْفَعَ بِهِ غَيْرِي، وَيُبَارِكَ فِيهِ، وَيُبَارِكَ فِيمَنْ نَشَرَهُ، أَوْ سَاعَدَ عَلَى نَشْرِهِ، ثُمَّ أَشْكُرُ كُلَّ مَنْ سَاعَدَنِي عَلَى إِخْرَاجِ هَذَا الْكِتَابِ فِي هَذِهِ الصُّورَةِ، وَتَأْلِيفِي هَذَا الْكِتَابِ مُحَاوَلَةٌ مِنِّي لِتَسْهِيلِ قَوَاعِدِ لُغَةِ الْقُرْآنِ، وَأَدْعُو اللهَ أَنْ أَكُونَ قَدْ وُفِّقْتُ فِي هَذَا، وَأَنْ يَكُونَ هَذَا الْكِتَابُ مِنَ الْكُتُبِ الْمَقْرُوءَةِ بِاسْتِمْرَارٍ، وَيُمْكِنُنِي الْقَوْلُ: أَنَّ هَذَا الْكِتَابَ الَّذِي أُقَدِّمُهُ لَكُمْ، وَالَّذِي يَعْلَمُ رَبِّي مَدَى تَعَبِي فِيهِ، وَعَنَائِي وَلَا أَعْفِي نَفْسِي مِنَ الْخَطَأِ، أَوِ النِّسْيَانِ فَهُمَا مِنْ صِفَاتِ الْبَشَرِ، فَإِنْ كَانَ فِي الْكِتَابِ مِنْ قُصُورٍ فَهُوَ مِنِّي، أَنَا لَا أَدَّعِي الْكَمَالَ؛ فَإِنَّ الْكَمَالَ لِلَّهِ - عَزَّ وَجَلَّ - فَقَدْ قَدَّمْتُ كُلَّ الْجُهْدِ لِهَذَا الْكِتَابِ، فَإِذَا وُفِّقْتُ فَمِنَ اللهِ - عَزَّ وَجَلَّ - وَإِنْ أَخْفَقْتُ فَمِنْ نَفْسِي، وَنَصِيحَتِي لِطُلَّابِ الْعِلْمِ أَنْ يَهْتَمُّوا بِمُمَارَسَةِ لُغَةِ الْقُرْآنِ الَّتِي تُسَاعِدُهُمْ عَلَى فَهْمِ الثَّقَافَةِ الْإِسْلَامِيَّةِ الَّتِي نَحْتَاجُهَا لِلنَّجَاحِ فِي الدُّنْيَا وَالْآخِرَةِ.

ثُمَّ أَشْكُرُ كُلَّ مَنْ شَارَكَ فِي مُرَاجَعَةِ الْكِتَابِ:

أ / عَلِي غُنِيم.
أ / مُحَمَّد السَّيِّد مَحْمُود.
أ / عَمْرُو جَمَال.
أ / عِمَاد فَتْحِي البَدْرِي.

# بعض من آراء من حصلوا على كتاب: ( كيف تتقن النحو؟ )

من الكتب الجميلة التي كنت عازمة أن أقتني نسخة منها هذا الكتاب (كيف تتقن النحو) ليس لشيء سوى أني أبحث منذ فترة طويلة عن كتاب مبسط لفهم قواعد النحو بطريقة مبسطة وإلمام ما تفرق منها في ذهني ثم الشروع لكتب التراث أو مع كتب التراث، هذا الكتاب وبدون أي مجاملة رائع
يشرح النحو بطريقة مبسطة مع ذكر الشواهد مع الاستشهاد بآيات من القرآن الكريم ثم يأتي بعد كل موضوع ويذكر ملخص للدرس وفيه أيضاً تدريبات والصفحة المقابلة لها فيها تدريبات محلولة الطبعة جيدة والكتاب منسق فيه تشجير للأبواب وهي طريقة سهلة أيضاً لتثبيت المعلومة هذا الكتاب في رأيي أنه يصلح للمبتدئين في علم النحو والإعراب يصلح لطلبة الإعدادية والثانوية يصلح أيضاً لطلبة الجامعات وما بعد الجامعي لمن عنده تشتت في المعلومة أو حتى لا يعرف كيفية الإعراب بداية موفقة ومجهود مبذول من المؤلف بالتوفيق دايما كيف تتقن

---

**كيف تتقن النحو**
كتاب عظيم حقيقي ومهما وصفته ومهما اتكلمت عن المجهود المبذول فيه مش هوفيه حقه.
كتاب يصلح للطلبة والخريجين والعاملين بمجال المراجعة اللغوية
كتاب شرحه مبسط وواضح جدا وبسيط وبالإضافة إلى تدريبات في نهاية كل درس، حقيقي ده أحسن وأسهل وأبسط كتاب نحو مر عليا، وطبعا المؤلف جمع كل قواعد النحو بطريقة واضحة جدا، كتاب عظيم وليا الشرف طبعا إني أحصل عليه، وبنصح كل اللي حابين يتعلموا النحو انهم لازم يحصلوا عليه.
شكرا يا أستاذ أحمد على مجهودك العظيم فيه وعلى كل تعبك وعلى طول بالك ووقتك اللي مش بتبخل بيه على أي حد، ربنا يوفقك ويفرحك وفي انتظار المزيد والمزيد.

هذا الكتاب (كيف تتقن النحو) من الكتب التي أبحث عنها منذ فترة طويلة فهو كتاب مبسط وشامل لفهم قواعد اللغة العربية بطريقة مبسطة ومؤجزه..
يشرح النحو بطريقة مبسطة مع ذكر الشواهد مع الاستشهاد بآيات من القرآن الكريم ثم يأتي بعد كل موضوع ويذكر ملخص للدرس وفيه أيضاً تدريبات محلولة الطبعة والكتاب منسق فيه تشجير للأبواب وهي طريقة سهلة جداً لتثبيت المعلومة..
فهو يُساعد المتعلمين والمبتدئين في فهم النحو ويرتب المعلومات وينسقها والمؤلف ( أحمد إسكندر ) لا يترك مسألة فيه من دون أن يأتي لها بشواهد أو بمثال يوضحها من القرآن الكريم أو الحديث أو الشعر.. ثم ذيله بثوابت إعرابية.
وللمؤلف شرح مرئي يبرز من خفي مكنوناته ما وراء الحجاب..
فتقيلة الله منك ويسرا الله أمرك ونفعكم الله بة وبعلمة في الدنيا والأخرة.

الحمد لله والشكر لله على أجمل وأعظم كتاب في النحو ✨
أشكر أخي وحبيبي فضيلة الأستاذ: - أحمد إسكندر فلقد أهداني كتابه المبارك • كيف تتقن النحو • والذي انشرح صدري برؤية هذا الكتاب المبارك الذي يُبسط ويسهل علم النحو لجميع المراحل الإعدادية والثانوية والجامعية ويفيد الطالب والمعلم، حيث قام فضيلة الأستاذ - أحمد إسكندر بجمع قواعد النحو بطريقة جدولية مبسطة وخرائط ذهنية يسيرة، واستدل على قاعدتة بآيات من القرآن الكريم وبعض من الأحاديث النبوية الصحيحة، وبعض من أبيات الشعر والأمثلة العصرية اليسيرة، فزينا كتابه بتدريبات وافية، وقد برع فضيلة الأستاذ: - أحمد إسكندر في إختيار أيسر الوسائل لإدراك القاعدة المرادة فضلاً عن الإعراب التفصيلي الذي يحتاجه طالب العلم في رحلة تحصيله لقواعد لغة القرآن الكريم.
لذلك أنصح كل محب للغة القرآن الكريم باقتناء هذا الكتاب المبارك لما حواه من الفوائد الجمة التي لم تجتمع في كتاب من قبل بهذا التنسيق المعاصر، جزى الله خيراً كثيراً فضيلة الأستاذ الدكتور أحمد إسكندر وكل من يخدم لغة القرآن الكريم ونفع الله بفضيلته الأمة الإسلامية.

هَذَا كِتَابٌ جَمَعْتُ فِيهِ قَوَاعِدَ النَّحْوِ الْعَرَبِيِّ

وَبَعْضِ مِنَ الْأَحَادِيثِ النَّبَوِيَّةِ الشَّرِيفَةِ مِنْ مَتْنِ الْأَرْبَعِينَ النَّوَوِيَّةِ
